# RECLAIM Documentation

This directory is the documentation source of truth for the RECLAIM project.

## Areas

- `product/` — product vision, requirements, user journeys, and product rules
- `architecture/` — system architecture and technical decisions
- `design-system/` — visual language and reusable UI components
- `screens/` — P0 screen specifications and implementation contracts
- `api/` — API contracts and endpoint specifications
- `database/` — data model, migrations, relationships, and constraints
- `security/` — authentication, authorization, privacy, and security requirements
- `testing/` — testing strategy and acceptance criteria
- `deployment/` — environments, CI/CD, hosting, and operational procedures
- `decisions/` — Architecture Decision Records and important project decisions

Specifications should be reviewed before implementation decisions are treated as final.
